# Evidence

The [evidence policy](evidence-policy.md) defines what a proof establishes and
what it leaves unverified. The [Windows real-machine validation](windows-real-machine-validation.md)
retains the dated host observation and its explicit acceptance limits. The
[listen-queue measurement](listen-queue-measurement.md) retains what two
kernels did with a connection that met a full queue, and the scripts that
measure it again.
